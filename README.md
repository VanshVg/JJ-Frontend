# Jay Jalaram Trading Co. – E-commerce Frontend

This is the frontend for **Jay Jalaram Trading Co.**, a full-stack grocery e-commerce platform built for a local retail shop. It supports customer and admin functionalities including orders, products, bonus points, payments, and more.

---

## Features

- **Authentication**
- **Browse Products**
- **Cart Management**
- **Order Placement**
- **Payment Integration**
- **Gift Points System**
- **Admin Panel**

---

## Tech Stack

- **React.js + Vite**
- **Tailwind CSS**
- **React Router**
- **Redux Toolkit**

---

## Installation & Setup

### Clone the repo
``` git clone https://github.com/VanshVg/JJ-Frontend.git ```

### Install dependencies
``` npm install ```

### Run in development
``` npm run dev ```
